# Out of scope

One file per rejected idea, kept so a decision is made once and linked afterwards rather than argued again.

Each file names the boundary, says what the plugin does support instead, gives the reason in terms a requester can weigh, and lists the escape hatches that already exist. `## Prior requests` records what people actually asked for, in their words, so the next duplicate is easy to match. Quote the words, never the person.

A reason that depends on how the world is today records that too, so the decision can be revisited when the world changes. Nothing here is permanent by virtue of being written down.
